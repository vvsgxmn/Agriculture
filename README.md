# 基于SpringBoot+Vue的助农电商系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) 

## 项目介绍

这是一个功能完善的助农电商平台系统，涵盖买家端、卖家端和管理后台三大模块，致力于搭建农产品从产地到消费者的直销桥梁。

### 功能模块

- **用户端（买家）**：农产品浏览与搜索、购物车管理、订单管理、产地溯源查询、助农资讯浏览（点赞/评论/收藏）、个人信息管理
- **卖家端**：仪表盘数据统计（销售趋势、商品类别分布）、店铺信息管理、农产品上架与管理、订单处理与发货
- **管理后台**：平台数据概览（用户数/卖家数/商品数/订单数）、买家管理、卖家管理、管理员管理、助农资讯管理、产地溯源管理

### 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis 2.3.2 + JPA + JWT + PageHelper
- **前端**：Vue 3.5 + Element Plus 2.9 + Vite 6 + ECharts 5.6 + Pinia
- **数据库**：MySQL 8.0
